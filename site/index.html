What it does

senses

Knows your laptop

Checks your Downloads, finds the biggest files, spots busy processes, and reads disk space and battery. It sees names, sizes and dates, never what's inside your files.

desktop pet

Lives on your screen

Walks back and forth, turns to face you when it talks, and answers in speech bubbles. Chat in its little window, or drag it somewhere else.

learn_skill

Teaches itself tricks

Ask for something it can't do yet and it writes a new Python tool. It shows you the code first, and nothing runs until you click Yes.

safe by default

You're in charge

Its tools only look; they never change anything. Its one action moves a file into a review folder, never deletes, and always asks first.

Ask it anything about your laptop

Type into Gemlin's little chat window and it answers in a speech bubble. When it uses a tool it tells you, and anything that changes your machine waits for you to click Yes.

Want a new personality? A dragon that hoards big files, an anxious librarian? Make your own.

Get started

You need Python 3.10 or newer and a Google account. It takes about five minutes.

  1. Get a free API key

    At aistudio.google.com/apikey. Keep it to yourself; never paste it into code.

  2. Download Gemlin

    git clone https://github.com/alexinslc/gemlin cd gemlin

    No git? Use Download ZIP, unzip it, and open a terminal in the folder.

  3. Install it

    python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt
    python -m venv .venv .venv\Scripts\activate pip install -r requirements.txt

  4. Add your key

    export GEMINI_API_KEY="your-key-here"
    setx GEMINI_API_KEY "your-key-here"

    Then close the terminal, open a new one in the gemlin folder, and run the activate line again.

  5. Wake it up

    python3 gemlin.py
    python gemlin.py

    Gemlin appears on your desktop with its chat window open. Say hi! Make your own Gemlin first if you like: the creator gives you one command that does it all.
